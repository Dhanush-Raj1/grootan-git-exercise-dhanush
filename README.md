## Description: 
- This repository contains the exercises/assignments given by Grootan Technologies. 
- The primary goal is to learn and practice git thoroughly. 
- The exercies are: 

    ###  Part A: Repository Setup (20 points) 
        1. Create a new GitHub repository named grootan-git-exercise-[yourname]
        2. Initialize with README.md containing:
            - Project title
            - Your name and date
            - Brief description
        3. Create a .gitignore file appropriate for Node.js/Java project
        4. Set up branch protection rules on main branch 


    ### Part B: Branching & Commits (30 points)
        1. Create a develop branch from main
        2. From develop, create feature branch feature/user-profile
        3. Make at least 5 meaningful commits with proper commit messages following convention:
            type(scope): description
            
            Examples:
                feat(profile): add user avatar upload
                fix(auth): resolve login redirect issue
                docs(readme): update installation steps

        4. Create another feature branch feature/settings-page
        5. Make 3 commits on this branch
